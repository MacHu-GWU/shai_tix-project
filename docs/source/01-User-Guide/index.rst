User Guide
==============================================================================

This guide covers the two primary ways to interact with ``shai_tix``:

1. **Python API** - Use the :class:`~shai_tix.tix.Tix` class directly in Python code
2. **CLI** - Use the :ref:`shai-tix <cli-reference>` command-line interface (designed for AI agents)

Both approaches share the same underlying storage and can be used interchangeably.
