Welcome to ``shai_tix`` Documentation
==============================================================================
.. image:: https://shai-tix.readthedocs.io/en/latest/_static/shai_tix-logo.png
    :target: https://shai-tix.readthedocs.io/en/latest/

A lightweight, file-system-based task management system designed for AI agents and CLI workflows.

**Core Philosophy:**

- **Zero database** - Your file system IS the database
- **Git-friendly** - Every change is trackable, mergeable, and reviewable
- **Two-level hierarchy** - Stories contain Tickets, nothing more
- **Agent-first** - Built for AI agents (like Claude Code) to read and manipulate
- **Stateless** - Current directory structure IS the current state



.. _install:

Install
------------------------------------------------------------------------------

``shai_tix`` is released on PyPI, so all you need is to:

.. code-block:: console

    $ pip install shai-tix

To upgrade to latest version:

.. code-block:: console

    $ pip install --upgrade shai-tix
